# Remove BG

[English](README.md) | 中文

一款浏览器图片编辑工具，支持去除纯色背景、裁剪、擦除和颜色处理，可导出原始分辨率的透明 PNG。所有图片处理均在浏览器本地完成。

**在线体验：** https://learningfromembodiedexperiencelab.github.io/remove_bg/

## 语言与外观

网页首次访问默认中文，点击页头的 **English / 中文** 按钮即可切换语言，浏览器会记住你的选择。旁边的主题按钮可切换浅色与深色模式。

界面采用 `ui/assets/` 中的 TrackNest UI 设计系统，使用暖灰配色、细边框、统一控件尺寸和响应式布局。

## 图片编辑

1. 将图片拖入上传区域，或点击上传。
2. 在 **去底色** 工具中点击 **拾取底色**，然后在图片上选择背景颜色。
3. 选择 **连通区域** 仅去除与选取位置相连的背景，或选择 **全局** 去除整张图片中的相近颜色。调整 **容差** 与 **边缘柔化**，查看实时预览。
4. 点击 **应用** 后即可使用 **橡皮擦**，清理残留背景，并使用缩放和 **撤销 / 反撤销**。放大后按住鼠标滚轮拖动可平移画布。
5. 使用 **裁剪** 选择比例，以及矩形、圆角或圆形形状。拖动裁剪框或边角调整，然后点击 **应用**。
6. 点击 **下载 PNG** 保存结果。**重置** 会重置当前工具，**恢复原图** 会恢复上传时的图片。

## 颜色工具

**颜色工具** 无需上传图片即可使用。通过饱和度与明度色板、色相滑块，或输入 HEX、RGB（0–255）、归一化 RGB（0–1）、HSV（角度 / 百分比 / 百分比）来预览和转换颜色。每种颜色值都提供复制按钮。

使用 **不透明度** 滑块或百分比输入框（0–100%），可在棋盘格上预览透明效果。颜色值及复制结果保留不含透明度的原始颜色。

**屏幕取色** 使用浏览器的取色接口，需要通过 HTTPS 或 localhost，在支持此功能的桌面浏览器（Chrome / Edge）中打开。按 Esc 可取消。取色器及放大镜由浏览器提供，网页无法调整放大镜位置或屏幕坐标映射。
